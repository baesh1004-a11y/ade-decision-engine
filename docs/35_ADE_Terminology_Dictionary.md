# ADE 용어 정의 사전 v1.0

## 1. 추천 엔진

| 시스템 용어 | UI 용어 | 정의 |
|---|---|---|
| Recommendation | 추천 결과 | ADE가 분석을 거쳐 저장한 추천 종목과 결과 |
| Decision | 최종 시스템 판단 | 추천·관찰·대기 등의 시스템 판정 |
| Reasons | 계산 과정 및 근거 | 추천 결과를 산출하는 과정에서 생성된 근거 문장 |

## 2. Replay 엔진

| 시스템 용어 | UI 용어 | 정의 |
|---|---|---|
| Replay | 유사 사례 분석 | 현재 주가 흐름과 과거 이벤트 이후 흐름을 비교하는 전체 분석 과정 |
| Replay Match | 유사 사례 | 현재 흐름과 유사하다고 판정된 개별 과거 사례 |
| Replay Top N | 주요 유사 사례 | 종합 유사도가 높은 과거 사례 목록 |
| Replay Prediction | 유사 사례 기반 전망 | 유사 사례 이후의 실제 경로를 유사도 가중치로 계산한 미래 전망 |

## 3. 유사도

| 시스템 용어 | UI 용어 | 정의 |
|---|---|---|
| Weekly Similarity | 주봉 흐름 유사도 | 현재와 과거 사례의 주봉 차트 형태 유사성 |
| STO Similarity | STO 구조 유사도 | 현재와 과거 사례의 STO 3계층 구조 유사성 |
| Final Similarity | 종합 유사도 | 주봉 흐름과 STO 구조를 결합한 최종 유사도 |
| Equivalent Week Index | 현재 대응 주차 | 과거 사례에서 현재 시점과 가장 유사한 주차 |
| Weeks Compared | 비교 기간 | 유사도 계산에 사용된 주 수 |
| Future Weeks Available | 이후 확인 가능 기간 | 과거 사례에서 매칭 이후 실제 성과를 확인할 수 있는 주 수 |

## 4. 전망 및 성과

| 시스템 용어 | UI 용어 | 정의 |
|---|---|---|
| Up Probability | 상승확률 | 유사 사례 가중치 기준 해당 기간의 상승 가능성 |
| Expected Return | 기대수익률 | 유사 사례의 가중 평균 수익률 |
| Median Return | 중앙값 수익률 | 유사 사례 수익률의 중앙값 |
| Max Return | 이후 최대수익 | 과거 사례 또는 전망 구간에서 기록한 최대 상승률 |
| Max Drawdown | 이후 최대낙폭 | 과거 사례 또는 전망 구간에서 기록한 최대 하락폭 |
| Expected Peak Day | 예상 최고점 도달일 | 유사 사례에서 최고점이 나타난 평균 시점 |
| Holding Days | 권장 보유기간 | 예상 최고점 시점을 기준으로 계산한 보유기간 |
| Target Return | 목표수익률 | 유사 사례 기반 참고 목표수익률 |
| Stop Return | 참고 손절폭 | 유사 사례 기반 참고 손실 제한폭 |
| Grade | 전망 등급 | 상승확률·기대수익·최대수익·낙폭을 종합한 A+~D 등급 |

## 5. 이벤트

| 시스템 용어 | UI 용어 | 정의 |
|---|---|---|
| Money Event | 대금 이벤트 | 최근 거래대금이 과거 기준 대비 크게 증가한 이벤트 |
| Candidate | 분석 대상 | 추천 엔진이 유사 사례를 검색하는 현재 종목 |
| Historical Event | 과거 이벤트 | Replay DB에 저장된 과거 대금 이벤트 사례 |
| Recent Money Ratio | 거래대금 강도 | 최근 거래대금이 120일 기준 대비 증가한 비율 |

## 6. 시스템 및 연동

| 시스템 용어 | UI 용어 | 정의 |
|---|---|---|
| DB | 데이터베이스 | 시세·추천·Replay·주문 관련 데이터 저장소 |
| KIS | 한국투자 API | 국내·미국 시세, 계좌 및 주문 연동 수단 |
| Yahoo | Yahoo Finance | 미국 및 보조 시장 데이터 공급원 |
| Sync | 마지막 동기화 | 시스템 데이터가 마지막으로 갱신된 시각 |

## 7. 운영 원칙

1. 코드 내부 용어와 UI 노출 용어를 분리한다.
2. 알고리즘·필드명은 기존 코드를 유지한다.
3. UI에서는 이 사전의 사용자용 용어를 일관되게 적용한다.
4. 동일한 개념을 화면마다 다른 이름으로 표시하지 않는다.
5. 새로운 기능은 UI 적용 전에 이 문서에 용어를 추가한다.
