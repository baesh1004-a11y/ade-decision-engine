# ADE UI v1

## 1. 확정된 1단 메뉴

```text
상황종합판 | 추천결과 | 주문 │ JP Radar
```

`JP Radar`는 `주문`과 구분선 및 넓은 간격으로 분리한다.

## 2. 상황종합판

2단 메뉴:

```text
시장 | 이벤트 | 내 투자
```

시스템 상태는 상황종합판에서 제외하고 모든 화면 하단 고정 상태바에서 표시한다.

## 3. 추천결과

2단 메뉴:

```text
국내 | 미국
```

추천목록은 순위별로 표시한다.

```text
순위 | 종목 | 추천점수 | JP Radar | 주문
```

- 종목 선택: 별도의 종목 상세화면
- JP Radar: 해당 종목의 JP Radar 화면
- 주문: 주문 후보에 추가하고 해당 종목 주문서로 연결

### 종목 상세화면

- 별도 화면
- 세로 스크롤
- 첫 번째 블록은 현재 차트
- 다음은 코드에서 제공하는 추천 상세 데이터 전체
- 돌아가기는 이전 추천목록으로 복귀

추천 상세 데이터:

1. 추천 이벤트 정보
2. 가장 유사한 과거 사례
3. 유사도 상세
4. 과거 사례의 실제 성과
5. 기간별 전망
6. 주문 판단용 예상치
7. 최종 시스템 판단
8. 계산 과정 및 근거
9. 유사 사례 Top N 전체 비교

국내와 미국은 같은 사용자 흐름과 레이아웃을 사용하지만 각 시장의 실제 데이터와 엔진 출력은 그대로 유지한다.

## 4. 주문

2단 메뉴:

```text
국내 | 미국
```

주문 기본화면은 관심종목 관리 화면과 유사하게 구성한다.

- 추천결과에서 주문 버튼을 누른 현재·이전 추천 종목 누적
- 종목 검색 및 직접 추가
- 주문 후보
- 보유종목

주문 후보 또는 보유종목을 선택하면 동일한 주문서가 열린다.

### 주문서

- 현재가, 등락률, 고가, 저가, 거래량
- 실시간 호가창
- 매수/매도
- 현금/신용
- 국내: SOR/KRX/NXT
- 미국: 시장 경로
- 지정가/시장가/조건부지정가/최유리/최우선
- 주문가격
- 주문수량
- 예상 주문금액
- AI 참고정보
- AI 추천주문
- 주문 실행

실제 브로커 제출 로직과 기존 알고리즘은 변경하지 않는다.

## 5. JP Radar

JP Radar는 두 경로로 진입한다.

1. 추천목록의 종목별 `JP Radar` 버튼
2. 1단 메뉴의 독립 `JP Radar`

독립 기본화면은 종목 검색을 제공하고, 추천목록에서 진입하면 해당 종목이 자동 선택된다.

## 6. 시스템 상태바

모든 화면 하단에 고정한다.

```text
AI | DB | KIS | Yahoo | Sync
```

상태 색상:

- 정상: 녹색
- 경고: 황색
- 오류: 적색
- 비활성: 회색

## 7. 구현 파일

```text
dashboard/ade_ui_v1_app.py
```

실행 예시:

```bash
streamlit run dashboard/ade_ui_v1_app.py
```
